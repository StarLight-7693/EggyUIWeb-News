## 项目简介

EggyUIWeb-News 是 EggyUI 官网的新闻站部分，负责承载 EggyUI 项目的新闻发布、公告通知、版本更新日志与博客内容等功能。作为官网的新闻站，它是用户获取 EggyUI 最新动态、了解项目进展的主要渠道。

本项目实现了完整的博客功能，支持文章列表、文章详情、分类与标签、时间归档等常见博客能力，适合用于发布项目公告、开发日志、技术分享与社区动态。

与主站一样，本项目为纯前端项目，**只有前端，没有后端**，所有页面与内容均在浏览器端完成渲染，不涉及服务端接口服务。

## 技术栈

- **静态站点框架**：VitePress
- **前端框架**：Vue 3
- **开发语言**：TypeScript
- **样式方案**：SCSS

## 部署方式

本项目与主站一致，部署于 **GitHub Pages**，通过静态托管的方式对外提供服务。由于没有后端，所有文章与新闻内容均以静态资源形式存在，更新时需重新构建并推送至部署分支。
